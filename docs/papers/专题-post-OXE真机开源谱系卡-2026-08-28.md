## 对照

| | OXE | AgiBot World |
|---|---|---|
| 组织 | 多机构异构联盟 | 单生态同构舰队（>100 台） |
| 规模 | 1M+ traj 拼盘 | 1.00M traj · **2976 h** 明确小时 |
| 对齐 | 粗 7D EE，坐标架不对齐 | 同构硬件，少 embodiment 税 |
| 质量 | 无统一 HITL 门 | HITL + 失败恢复 ~1% |
| 长程 | 大量短轨迹 | 多 **30–60 s** |
| 样板模型 | RT-1-X / RT-2-X | GO-1 ViLLA 潜动作 |
| 角色 | **公制基线** | **质量×规模标杆**（vs OXE +30%） |

## 三句结论
1. OXE 解决 **「能不能共训」**；AgiBot 解决 **「共训该用什么样的真机小时」**。  
2. post-OXE 挖掘三线：**(a) 同构高质量操作系统 (b) OXE 用法/次优过滤 (c) 单域极致（工业力 D）**。  
3. 与 EGO 并行：真机 AgiBot 轨迹 power-law ↔ 人侧 EgoScale 动作 loss log-linear。
