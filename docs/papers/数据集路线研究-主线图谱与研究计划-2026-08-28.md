# 数据集路线研究 · 主线图谱与研究计划

> **定位**：在研究纲领(四类数据四层栈)之上，把"造/配/混数据"拆成**若干条可执行的研究路线**，每条带研究问题、已证证据、判据实验、优先级——然后**一条一条走**。
> 数据来自：研究纲领 + 证据清单 + EGO 数据线(6集+产业勘查+企业深读)。核验级别沿用(✔/⚠)。

---

## 一、路线图谱（研究主干）

工业界 + 学术界的数据供给可归为 **4 条主路线 + 2 条胶水/横切路线**：

| 路线 | 一句话 | 哲学 | 代表(已核验) |
|---|---|---|---|
| **R1 · EGO/人数据** | 用人类第一视角行为做海量供给 | B | EgoSuite-Open100K、WIYH、EgoVerse、Open-AoE、Ego-OSCAR、EgoInfinity |
| **R2 · UMI/通用接口** | 低成本设备采"灵巧+跨本体" | UMI | KoalaGripper、YUBI、OnePolicy-ManyEmbodiments、HRDexDB |
| **R3 · 仿真/合成** | 用引擎/世界模型无限生成 | C | NVIDIA GR00T/Cosmos、AgiBot Digital World、EgoInfinity(引擎面) |
| **R4 · 真机遥操** | 目标本体金标准；**精密分支见哲学D** | A (+**D精密力**) | AgiBot World(2503.06669)、π0(2410.24164)、OpenX(2310.08864)、**ManuFacet-1K(~1000h力同步)**、GraspVLA |
| **R5 · 统一动作空间**(胶水) | 把四路混进同一种可训表示 | 跨路 | π/π0.5、OnePolicy-ManyEmbodiments、UCAG-P、OpenX 格式 |
| **R6 · 物理/接触/触觉**(横切) | 把"物理可信"塞回数据；**工业闭环标杆=ManuFacet** | 横切 | WIYH(VLTA)、HRDexDB、CHORD、MimicTouch、GelSight、**ManuFacet F/T+接触相** |

> 主线关系：R1–R4 是四类数据**造**的路线；R5 是把它们**混/配**的胶水；R6 是贯穿各路的**质量横切**。一次训练=四层栈(纲领)。

---

## 二、每条路线：主张 / 证据 / 缺口 / 判据实验 / 优先级

### R1 · EGO/人数据路线（⭐ 首推先走）
- **主张**：EGO 是唯一能"不用机器人就海量采"的源；规模化供给的关键是**人数据 → 可训动作**的桥。
- **已证**：EgoVerse(1362h)、Open100K(10万h,产业背书)、EgoScale(20,854h,log-linear scaling law)、EgoEngine(ego→高保真机器人视频)。
- **缺口**：**企业级 EGO 数据(光轮/它石)标注层次细粒度未公开**(L0–L4 空洞)；"大规模×到L4可行动作"仍无一套满足。
- **判据实验**：拿 EgoSuite/WIYH 与 EgoInfinity/Open-AoE 工具链做端到端，测"人数据→(retarget/潜动作)→目标本体"的**迁移收益**；以及"标注层次越高,越少数据可达同等性能"(L1..L4 消融)。
- **优先**：**P0**（新产业数据+主线核心+缺口实证可补）。

### R2 · UMI/通用接口路线
- **主张**：手持低成本设备采"跨本体可用的灵巧数据"；夹爪不变动作空间是命门。
- **已证**：KoalaGripper(设备+采集协同设计)、OnePolicy-ManyEmbodiments(一个权重吃多本体)、HRDexDB(配对)。
- **缺口**：UMI 数据**动作空间设计**如何影响跨本体迁移(定量证据少)。
- **判据实验**：同一批手持示范，用"夹爪不变 vs 相机中心 vs 手部关节"三种动作空间训三个本体,量化迁移曲线。
- **优先**：**P1**。

### R3 · 仿真/合成路线
- **主张**：无限生成、全标注、可补失败/边界；短板是 sim2real+行为真实性。
- **已证**：NVIDIA GR00T/Cosmos(合成引擎,W态)、AgiBot World 显示真实数据>仿真泛化、BehaviorWorldGen(行为真实性坑)。
- **缺口**：**世界模型产出"可执行、可训"数据的闭环**仍缺量化判据。
- **判据实验**：同任务用"仅仿真 vs 仿真+real2sim校准 vs 混真机"三组训练,测真实部署成功率与 sim2real 偏移。
- **优先**：**P1**。

### R4 · 真机遥操路线
- **主张**：目标本体金标准最直接但最贵,只作精调/验证(四层栈第④层)。
- **已证**：AgiBot World(>100万轨迹,+30% over OpenX)、π0(流模型)。
- **判据实验**：给定预算,真机样本 vs (EGO预训练+少真机)的收益曲线,找"真机饱和点"。
- **优先**：**P2**(已有较充分证据)。

### R5 · 统一动作空间路线（胶水）
- **主张**：统一动作空间(相机中心/夹爪不变/隐式动作)是可微不变量,把四路混进同一语料。
- **已证**：π/π0.5、OnePolicy-ManyEmbodiments、UCAG-P、OpenX 格式。
- **关键决策**：**A4 裁决实验**(UAS×OT 一石三鸟)——见 EGO 蓝本 B 篇。
- **优先**：**P0**(与 R1 联动的关键胶水,待 A4 实跑)。

### R6 · 物理/接触/触觉路线（横切）
- **主张**：EGO/跨本体先天拿不到物理/接触真值;触觉是"物理可信"的数据级补丁。
- **已证**：WIYH(VLTA 把触觉列为一级模态)、HRDexDB(配对接触力)、CHORD(接触力)、GelSight。
- **判据实验**：前缀接触觉流 vs 纯视觉,测高接触任务的失败率下降。
- **优先**：**P1**。

## 三、优先级与执行序（先走哪条）
1. **P0 · R1 EGO/人数据路线**：最贴近主线、有新产业数据(光轮/它石)可实证、缺口可补。
   - 首步动作：**把 EgoSuite-Open100K / WIYH 并入 EGO 数据集对照(6→8集)**，并把两者标注层次 L0–L4 填实(取 README/白皮书)。
2. **P0 · R5 统一动作空间**：与 R1 联动(把 EGO 混成可训语料的胶水)；启动 A4 裁决实验设计。
3. **P1 · R3 仿真 + R6 触觉**：两条都已有产业样本,做定量判据。
4. **P1 · R2 UMI**、**P2 · R4 真机**。

## 四、一句话口径
**数据集路线研究 = 把"数据怎么造(R1–R4)、怎么混(R5)、怎么保物理可信(R6)"六条路各配研究问题+判据实验,并按"离主线近+有产业实证+可补缺口"排序,一条一条走;当前先走 R1 EGO/人数据路线。**
