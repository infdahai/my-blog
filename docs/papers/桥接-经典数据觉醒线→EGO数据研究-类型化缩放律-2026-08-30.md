# 桥接 · 经典「数据觉醒」线 → EGO 数据研究

> 目的：把经典 36 篇里的「数据觉醒」线（Chinchilla / Scaling Laws），显式接到本 vault 的「数据×训练」研究纲领上，说清**我们到底在补经典线缺的那一块**。

---

## 1. 一句话命题

经典线证明了：**有效训练随数据"量"按可预测的缩放律增长（Chinchilla 20:1）**。  
我们的 EGO/企业数据研究，问的是经典的**下一层、也是它没答的维度**：

> **当数据"性质"不同（形态、质量、配对、力同步、本体）时，"多少小时才算有用训练"如何缩放？**

这叫 **类型化缩放律（typed scaling law）** —— 在"参数量-数据量"的 20:1 之上，再补一条"**有效小时 ↔ 数据性质**"换算律。

---

## 2. 经典线给我们的坐标（沿用）*

| 经典视角 | 变量 | 我们补的变量 |
|---|---|---|
| Chinchilla | token 数/参数比 = 20 | **有效小时**/任务（数据性质加权后的"有效量"） |
| Scaling Laws | N, D, C 幂律 | 数据**性质轴**（EGO/仿真/力同步/配对/真机） |
| RefinedWeb | 过滤质量≈能力 | 采集协议/标注层/失败保留 = 数据**质量门** |

→ 换句话说：经典线把所有 token 当**同质**；我们必须做**异质**（不同来源的小时含金量不同）。

---

## 3. 已经握在手里的"类型化"证据碎片（本 vault）

| 来源 | 证据 | 说明 |
|---|---|---|
| **EgoScale**（2602.16710） | 人动作 loss 随小时 **log-linear：L=0.024−0.003·ln(D)** | 人 EGO 数据"量"有自己的一条律 |
| **AgiBot World**（2503.06669） | 真机轨迹 **power-law r=0.97** | 真机数据"量"又一条律 |
| **EgoVerse**（2604.07607） | **无 domain-aligned 锚，8h 多样人数据不显著增益** | **"量"依赖"对齐/配对"才生效** ← 类型化的核心证据 |
| **ManuFacet**（工业力同步） | ~1000h 力同步，82% vs 15% | 力同步的"稀有小时"含金量极高 |
| **MimicTouch**（2310.16917） | 人手触觉 104 条/hr·83%，遥操 19/hr | 采集形态决定**有效产出率** |
| **CHORD**（2607.00033） | 仿真+力引导，1831 任务·82.12% | 仿真力引导可规模替代真机遥操 |

**合起来的一句话**：存在**不止一条**数据缩放律；每条律的"斜率/起点"由**数据性质**决定；且性质间存在**锚定/兑换关系**（如 EgoVerse：2h aligned 能撬动 8h 多样；EgoScale：50h 人 + 4h 机 mid-train 才最优）。

---

## 4. 我们要回答的"兑换方程"

把经典 20:1 推广为一张**数据性质换算表**（部分是 ⚠待实测的假说）：

| 1 单位 | ≈ 多少单位"通用真机小时" | 判据 |
|---|---|---|
| 真机通用（基准） | 1 | 尺度基准 |
| 人 EGO（有对齐锚） | EgoScale：对数律，短程超线性、长程摊薄 | 相对真机 X 倍（⚠需实测） |
| 人 EGO（无锚） | **≈0**（EgoVerse 实证：不增益甚至负迁移） | 必须配锚 |
| 配对金标准（demo 带目标结局） | 高倍（判据任务：+X%） | R5/蓝本 A |
| 精密力同步工业（ManuFacet 类） | 接触类显著、通用类存疑 | D 线 |
| 仿真（力引导 RL，CHORD 类） | 接触丰富可规模；sim2real 风险 | C 线 |
| 失败/次优轨迹 | 相对成功轨迹的一等监督（REASSEMBLE） | 谱系尺子 |

> **研究纲领的北极星问题** = 给这张表填上**可证伪的定义与基准**，让"数据供给"从工匠性判断变成**可预测、可预算**的工程（这是 Chinchilla 对"量"做的事，我们对其做"性"）。

---

## 5. 这如何反过来指导"读经典"

- 读 **InstructGPT/Tulu**：能力 vs 对齐 → 对应我们"真机可用" vs "配对金标准"两个目标。
- 读 **MOE / LoRA**：参数效率 → 对应我们对"数据受限时如何用小模型榨干有效小时"的考量。
- 读 **ReAct/CoT**：交互/推理 → 对应"数据不只喂策略，还喂世界模型/规划"（EgoWAM 世界表示）。

---

## 6. 结论

经典「数据觉醒」线把**"数据数量"确认为有效训练的短板**（Chinchilla）。  
本 vault 的 EGO/企业数据研究，就是把它**推进到"数据性质"**：构造**类型化缩放律**（有效小时/性质轴），回答"哪种数据、多少量、怎么配对，才决定有效训练"。  

→ **Chinchilla 问"多少 token，模型才算装得满"；我们问"哪一种数据，多少小时，才最有效地训练一个具身智能"。**
