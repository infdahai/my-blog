# 企业数据集深读 · 首期探测（设计 + 论文细节）

> 从企业视角逐家拆解：**设计意图 / 数据集构成 / 论文核验 / L0–L4 标注层次 / 佐证价值**。
> 精度规范：✔=已核验(arxiv/网页)；⚠=公开信息但 id/细粒度规格待实测；**光轮/它石为2026新发布、无论文、细粒度 README 因网络不可达待实测**——不臆造数字。

---

## 1 · 光轮智能 · EgoSuite-Open100K（人/EGO 哲学）
- **设计意图**：把"具身最贵的训练数据(人类行为)"做成首个 10万h 级开源标品；宣称"仿真合成=Token化数据"、"1h仿真多样性>100万采集场"；5年目标 100亿h。
- **构成**：**10万小时 全模态人类行为**数据（HF/AtomGit 开源，捐开放原子基金会）；附**评测标准化 + 触觉基础设施**（"双轮策略：数据驱动/标准先行"）；联手58同城生态。
- **论文**：⚠ 无（2026 WRC 公告；细粒度模态/传感器配置待实测）。
- **L0–L4**：规模是量级(10万h)，但**标注层次**未公开细节(⚠)。它补的是 EGO 数据线"大规模×全模态供给端"那一格(呼应 S4 三件套之"低门槛采集")。
- **佐证**：产业证实"EGO 人类数据规模化"有商业买单（佐证2 升级版）；且其"仿真=Token化"主张 vs 真数据,正是 C vs B 哲学之争的样本。

## 2 · 它石智航(TARS) · WIYH = World In Your Hands（B+触觉 哲学）
- **设计意图**："人中心数据引擎"新范式；主打**VLTA = 视觉-语言-触觉-动作**四模态真实世界数据；自诩"领先特斯拉半年"。
- **构成**：全球首个**大规模真实世界 VLTA**多模态数据集；联想创投被投。
- **论文**：⚠ 无（公司公告；规模/采集/标注粒度待实测）。
- **L0–L4**：⚠ 细粒度待实测；但**触觉被设计为一级模态(与视觉/语言/动作并列)**——这本身就是设计层信号,印证"物理/接触可信"是行业共识未闭环项。
- **佐证**：头部企业把**触觉写进数据标准**（佐证3）；人中心真实数据 vs 光轮人数据 vs 智元真机,构成 B 哲学内部分岔。

## 3 · 智元 AgiBot · AgiBot World Colosseo（A+C 哲学）✔ 有论文
- **设计意图**：用大规模**真实遥操+仿真**做可泛化操作平台;设计"标准化采集管线+人机校验"保质量。
- **构成**：**>100万轨迹 / 217任务 / 5部署场景**(数量级超既有数据)；**夹爪→灵巧手→视触觉传感器可扩展**；附 **GO-1(Genie Operator-1)** 潜动作策略最大化数据利用；另有 AgiBot Digital World 仿真。
- **论文**：✔ **arxiv 2503.06669**。性能：预训练后比 Open X-Embodiment **平均提升30%**(域内&域外)；GO-1 擅长真机灵巧+长程任务。→ **设计结论:潜动作表示(latent action)提高数据利用率 + 真实数据压倒仿真泛化**。
- **L0–L4**：生产级全链路,含真机可行动作(L4).是"真机遥操"支点。

## 4 · Physical Intelligence · π0 / π0.5（A 哲学）✔ 论文
- **π0**：✔ arxiv **2410.24164** — 视觉-语言-动作**流模型(flow)**，面向通用机器人控制；跨本体预训练。
- **π0.5**：开源权重+openpi + 数据/工具链开源（⚠ id 待核）。
- **设计结论**：π系列证明**"数据+流模型"跨本体可成通用底座**——但数据本身(采集自多家)未完整开放,处于"模型开源/数据半开"。

## 5 · Google · Open X-Embodiment / RT-X（A+跨本体）✔ 论文
- **构成**：多机构多本体异构机器人数据统一格式;RT-X 模型。
- **论文**：✔ arxiv **2310.08864**。
- **设计结论**：是"跨本体/统一动作空间"的原始样板——**数据格式统一(Embodiment-agnostic)是跨本体泛化的前提**(呼应统一动作空间线)。

## 6 · NVIDIA · GR00T 系 + Cosmos（C 仿真哲学）⚠ id待核
- **设计**：GR00T-N1/N1.5(开源人形基础模型) + **GR00T 数据集(GROOT-1M,Isaac/Omniverse/动作仿帧合成演示)** + **Cosmos 世界模型(Cosmos-Predict/Reason,生成可控世界数据)** + GR00T-Dreams(奖励/数据合成) + GR00T-Teleop 遥操作框架。
- **设计结论**：NVIDIA 把**"仿真合成+世界模型"做成无限数据引擎**,走 C 哲学;与真机/人数据形成三哲学对立。
- **论文**：⚠ 有技术报告但本会话 id 未核验到,不臆测。

## 首期探测结论
1. **有论文的(AgiBot/π0/OpenX)落在"真实数据"轴**,且共识是"真实数据+潜动作表示>仿真"；唯一全线押仿真的是 NVIDIA(仍是最完整的世界模型数据引擎)。
2. **两家新玩家(光轮/它石)ALL-IN 人/EGO+触觉**,把数据供给从"机器人采集"转向"人类生活/手部行为"——正中 EGO 数据线。
3. **缺口**:企业级 EGO 数据(光轮/它石)目前**无论文、标注层次细粒度未公开**——这正是我们"数据×(标注层次)研究"能补的洞;建议下一轮拿到两者 repo/白皮书把 L0–L4 填实。
