# Papers

Obsidian Citations 插件根据 `90_Templates/paper-note.md` 自动生成骨架，文件名
使用 Better BibTeX 生成的 citekey。

PDF 原件由 Zotero 管理，存储在 iCloud (`~/Library/Mobile Documents/com~apple~CloudDocs/Zotero_Data/`)，
不进入 Git，不在博客发布。
